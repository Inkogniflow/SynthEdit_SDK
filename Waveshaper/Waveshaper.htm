SXE Waveshaper

Stereo-Waveshaper mit einer Tabelle aus Formeln. Mit Position scrollt man durch die Tabelle wie bei einem Wavetable-Oszillator; zwischen zwei Nachbarn wird stufenlos überblendet. Vier Modulationseingänge A–D speisen Variablen in den Formeln.

Pins

Left In, Right InAudio, ±5 V entspricht x = −1…+1
Position0…10 V = erste…letzte Funktion (Morph dazwischen)
A, B, C, DAudio, Bereich immer −5…+5 V (wird darauf begrenzt), in der Formel auf den angegebenen Bereich skaliert
Mix0…10 V = trocken…nass (trocken ist latenzkorrigiert)
TableSaturation, Folding, Harmonics, Asymmetric, Digital oder Custom
Functionseigene Funktionsliste, gilt bei Table = Custom
OversamplingOff, 2x, 4x (Standard), 8x – eingeschaltet 32 Samples Latenz
DC Blockentfernt Gleichanteil (asymmetrische Kurven)
Display Table / Curvean SXE Waveshaper Display anschließen (im selben Container)

Variablen

A(-1.5, 3.3) heißt: −5 V am Pin A → −1.5, 0 V → 0.9, +5 V → 3.3. Ohne Klammer gilt A = A(-1, 1). Dieselbe Variable darf in einer Formel mehrfach mit verschiedenen Bereichen vorkommen.

Funktionsliste

Einträge durch ; oder Zeilenumbruch trennen, optional mit Namen davor. Zeilen mit # oder // sind Kommentare. Max. 64 Funktionen.

Clean: x
Drive: tanh(x*A(1,10))
Fold: fold(x*A(1,6) + B(-1,1))
Crush: quant(x, 2^A(1,8))

Syntax

Eingang x (−1…+1), Ergebnis y (−1…+1 = ±5 V, begrenzt auf ±20 V). Konstanten pi, e.

Operatoren + - * / % ^, Vergleiche < > <= >= == != (ergeben 0/1), && || !, implizite Multiplikation 2x, 3(x+1).

Funktionen sin cos tan asin acos atan atan2(y,x) sinh cosh tanh exp log log2 log10 sqrt abs sign floor ceil round frac mod(a,b) pow(a,b) min max clamp(v,lo,hi) if(c,a,b) lerp(a,b,t) step(edge,v)

Waveshaping sat(v) = v/(1+|v|), hard(v) = Clip auf ±1, fold(v) Dreiecks-Fold, wrap(v) Wrap-around, spow(v,p) = sign(v)·|v|^p, cheb(n,v) Tschebyschow-Polynom Tn (n-te Harmonische bei vollem Sinus), quant(v,s) Stufen von 1/s, sinc(v).

Fehlerhafte Formeln lassen das Signal unverändert durch; das Display zeigt die Fehlermeldung rot an. NaN/Unendlich (z. B. log(x) bei x ≤ 0) werden zu 0.

SXE Waveshaper Display

2D: aktuelle Übertragungskurve, Diagonale y = x als Referenz, blaues Band = Eingangspegel, Marker auf der Kurve. 3D: alle Funktionen der Tabelle, aktuelle hervorgehoben. Oben Name und Index, unten Formel und die aktuellen Werte von A–D (im Bereich der aktuellen Formel). Farben als Pins (AARRGGBB oder RRGGBB, # erlaubt), dazu Line Width, Show Grid, Show Text, Font Size.
