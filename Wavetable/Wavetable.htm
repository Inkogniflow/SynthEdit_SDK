Wavetable Osc

Band-limited wavetable oscillator. Each table holds up to 256 frames; Position morphs smoothly between them. Tables are stored as half-octave mip levels and read with Hermite interpolation, so there is no audible aliasing.

  • Pitch - 1 V/oct, 5 V = 440 Hz.
  • Position - 0 V = first frame, 10 V = last frame. Can be modulated at audio rate.
  • Phase - phase offset, 0..10 V = 0..360 degrees. Audio rate, so it also works for phase modulation.
  • Sync - a rising edge through 0 V restarts the cycle (hard sync).
  • Table - Classic (sine, triangle, saw, square), PWM, Harmonic Sweep, Formant Vowels, Sync Sweep, Wavefold, WAV File or File List.
  • Wavetable File - a .wav wavetable, used when Table = WAV File. Serum-style files (2048 samples per frame) load directly; a 'clm ' chunk sets a different frame size. A short file is used as a single cycle.
  • File List - used when Table = File List. A folder (all .wav files in it, sorted by name, "wave2" before "wave10"), or several files and/or folders separated by ';'. All waves are joined into one table and Position blends through them. Each file without a 'clm ' chunk counts as one single cycle (any length), unless its length is an exact multiple of 2048 samples. Every frame is normalised, so the blend stays even in level. Up to 256 frames in total.
  • Voices - unison voices, 1 to 16.
  • Detune - 0..10 V. The outer voices are detuned up to +/-100 cents; the curve is squared, so 5 V = +/-25 cents.
  • Width - 0..10 V, how far the unison voices are spread across the stereo field.
  • Pan - -5 V = left, 0 V = centre, +5 V = right (balance law: centre is 0 dB on both sides).
  • On - off = silence; the outputs stop streaming so the module uses no CPU.
  • Left, Right - audio, +/-5 V at centre. Several voices are scaled by 1/sqrt(Voices).
  • Display Table / Display Wave - connect to the Wavetable Display.

If a file or folder can't be read, the Classic table is used. Built-in tables are calculated the first time they are used (about 0.2 s) and then shared by all voices.

Wavetable Display

Shows the wavetable of a connected Wavetable Osc. Put it in the same container as the oscillator. In polyphonic patches it follows the most recently played voice.

  • Table / Wave - connect to the oscillator's Display Table / Display Wave.
  • View - 2D shows the frame being played; 3D shows all frames with the current one highlighted.
  • Background Color, Grid Color, Wave Color, Fill Color, Frames Color - hex colours AARRGGBB (e.g. FF5BE7FF) or RRGGBB. A '#' is allowed. An empty pin uses the default colour.
  • Line Width - outline width of the current waveform in pixels.
  • Show Grid - grid lines (2D) or floor outline (3D).
