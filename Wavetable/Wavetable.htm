Wavetable Osc

Band-limited wavetable oscillator. Each table holds up to 256 frames; Position morphs smoothly between them. Tables are stored as half-octave mip levels and read with Hermite interpolation, so there is no audible aliasing.

  • Pitch - 1 V/oct, 5 V = 440 Hz.
  • Position - 0 V = first frame, 10 V = last frame. Can be modulated at audio rate.
  • Sync - a rising edge through 0 V restarts the cycle (hard sync).
  • Table - Classic (sine, triangle, saw, square), PWM, Harmonic Sweep, Formant Vowels, Sync Sweep, Wavefold, or WAV File.
  • Wavetable File - a .wav wavetable, used when Table = WAV File. Serum-style files (2048 samples per frame) load directly; a 'clm ' chunk sets a different frame size. A short file is used as a single cycle. If the file can't be read, Classic is used.
  • Output - audio, +/-5 V.
  • Display Table / Display Wave - connect to the Wavetable Display.

Wavetable Display

Shows the wavetable of a connected Wavetable Osc. Put it in the same container as the oscillator. In polyphonic patches it follows the most recently played voice.

  • Table / Wave - connect to the oscillator's Display Table / Display Wave.
  • View - 2D shows the frame being played; 3D shows all frames with the current one highlighted.
  • Background Color, Grid Color, Wave Color, Fill Color, Frames Color - hex colours AARRGGBB (e.g. FF5BE7FF) or RRGGBB. A '#' is allowed. An empty pin uses the default colour.
  • Line Width - outline width of the current waveform in pixels.
  • Show Grid - grid lines (2D) or floor outline (3D).
